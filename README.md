## My work at my Industrial Placement (2024-2025)
For 14 months I worked at Elanco Animal Health as part of the IT team of their Compliance sector. I worked mainly as a Full-Stack Web developer on a modern tech stack web app.

### Maintenance and Feature addition to a live, modern T3 web app.
- Maintained in a Scrum team setting using Jira, with React, Next.js and Typescript front-end and Postgres and Express.js back-end.
- Added key-features like Unsaved Changes warning pop-ups and timeout powered browser push Notifications implemented via React Hooks.
- The app handled sensitive personal information and I dealt with a potential SQL Injection vulnerability.
- Familiar with the CI/CD pipeline of the app, managing build states/quality stages.
- Dealt directly with customers bug reports and feature requests, owning that ticket and following up personally for more information and satisfaction of the change.
- Independently added a suite of front-end tests as none existed. Used React Testing Library with Vitest to create Cucumber unit tests that mirror the user stories of tickets.
- Led development on an interactive dashboard page of high-level analytics, with a world map that users could select countries to power a set of four charts. Used AgCharts and the SVG renderer D3.js to make the map. The map and charts pulled from a live database back-end of Postgres and Express.js. I used Google Cloud Storage Buckets to host the large world-map GeoJson file externally, to reduce docker and codebase size by 75%. Repeatedly communicated with stakeholders about requirements and improvements and presented my progress for feedback

- Repeatedly communicated with stakeholders about requirements and improvements and presented my progress for feedback
